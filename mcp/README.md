# aiwiki-mcp

MCP server for [AiWiki](https://xuebinma.github.io/AIWiki/) — search and read an encyclopedia of **AI-coding pitfalls** and **LLM privacy protection**, written from the AI's first-person perspective. Bilingual (EN/中文), every entry evidence-tagged (papers / vendor docs / CVEs).

把 AiWiki 百科变成你编辑器里的工具：遇到「AI 越聊越笨」「幻觉 API」「测试被糊弄」这类反复出现的问题时，让你的 AI 助手直接查到对应误区条目、机制解释和工程护栏。

## Tools

| Tool | What it does |
| --- | --- |
| `aiwiki_search` | Search entries by keywords or a short problem description (Chinese or English). Optional `subject` filter (`coding-pitfalls` / `privacy`), `lang`, `limit`. |
| `aiwiki_get_entry` | Fetch the full markdown by the canonical `id` returned by search, e.g. `privacy:mechanisms`. Unique legacy IDs still work; pass `subject` to disambiguate an old ID. |

Content is fetched from the site's public index (`/api/index-v2.json`, cached for up to ten minutes) and GitHub. Content updates do not require republishing the package; the articles, index and client still need maintenance. The legacy `/api/index.json` endpoint retains v1 IDs for existing clients; it cannot repair old clients' ambiguous same-name lookup, so upgrade the client for subject-safe retrieval. Index v2 exposes bilingual summaries, review dates, sources and privacy maturity. IDs include the subject so similarly named pages cannot select the wrong topic.

The index records a deterministic source-content digest. CI builds also record `GITHUB_SHA` and pin full-text URLs to that commit, keeping retrieved articles aligned with the deployed index. Local generation uses `main` URLs when no build commit is supplied. These provenance fields describe the source snapshot, not a claim that every article was freshly fact-checked.

## Install

### Claude Code

```bash
claude mcp add aiwiki -- npx -y aiwiki-mcp
```

### Other MCP clients (Cursor, Windsurf, Claude Desktop…)

```json
{
  "mcpServers": {
    "aiwiki": {
      "command": "npx",
      "args": ["-y", "aiwiki-mcp"]
    }
  }
}
```

### From a repo checkout (no npm)

```bash
git clone https://github.com/XuebinMa/AIWiki.git
cd AIWiki/mcp && npm install
claude mcp add aiwiki -- node /path/to/AIWiki/mcp/src/server.js
```

## Development

```bash
npm install
npm test          # search, loader, canonical identity and real-index regression suites
AIWIKI_INDEX_URL=http://localhost:8931/api/index-v2.json npm start   # point at a local index for dev
```

The index is generated by `scripts/gen-mcp-index.js` at the repo root (wired into the site's `prebuild`) and served as `https://xuebinma.github.io/AIWiki/api/index-v2.json`, with a compatibility v1 index at `/api/index.json`.
