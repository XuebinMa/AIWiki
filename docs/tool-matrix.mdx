# 工具矩阵

工具能力变化很快。这页把**本书覆盖范围**与**产品当前能力**分开：文章没写某工具的差异，不代表产品没有该能力。每次比较都应注明 CLI/IDE/云端形态、版本、平台和实际权限模式。

## 当前核查入口

| 工具 | 本次已核的机制 | 使用前还要确认 |
|---|---|---|
| Claude Code | 指令与执行策略分层；内置沙箱主要覆盖 shell 及子进程 | 文件/网页工具、MCP、hooks、敏感读取与无沙箱重试的范围 |
| Codex | 有 `/plan` 与原生 subagents；子代理继承父级安全约束 | 具体界面、配置覆盖、网络/文件限制及工作区是否独立 |
| Gemini CLI | 有 Plan Mode 与原生 subagents | 当前默认模式、策略与子代理工具权限 |
| Cursor | 有原生 subagents；官方说明 permissions allowlist 不是安全保证 | 编辑器/CLI/云端的运行位置、沙箱与团队策略 |
| GitHub Copilot | 必须区分补全、IDE agent、云端 coding agent 与 code review | 每个产品形态的指令支持、工具权限、网络和审查范围 |

核查日期：**2026-10-29**。这些是已查机制，不是完整功能表，也不是安全强度排名。默认值与“某功能不存在”最容易过时；没有充分证据时保留未知。
