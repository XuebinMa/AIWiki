> 一句话摘要：这份模板是 Claude Code 的交互审批起点。它拦截匹配到的工具调用；文件与网络是否真正隔离，还要检查沙箱、凭据和 MCP 的边界。复制前先确认当前权限模式，别把命令清单当成完整安全边界。

## 模板本体

```json
{
  "permissions": {
    "deny": [
      "Read(.env)",
      "Read(.env.*)",
      "Read(secrets/**)",
      "Bash(rm *)",
      "Bash(sudo *)",
      "Bash(dropdb *)"
    ],
    "ask": [
      "Edit",
      "Write",
      "Bash(git branch *)",
      "Bash(git commit *)",
      "Bash(git push *)",
      "Bash(git reset *)",
      "Bash(npm *)",
      "Bash(pnpm *)",
      "Bash(npx *)"
    ],
    "allow": [
      "Read",
      "Glob",
      "Grep",
      "Bash(pwd)",
      "Bash(git status)",
      "Bash(git diff)"
    ]
  }
}
```

## 怎么用

放进项目的 `.claude/settings.json`，或按当前官方文档调整为个人配置。匹配时 `deny` 优先于 `ask`，`ask` 优先于 `allow`；最终行为还受权限模式、托管策略和沙箱设置影响。

- **先核查命令会做什么。** `git branch` 既能列分支，也能删除或重置分支，所以这里整类保留确认。`npm test`、lint、build 都能执行仓库脚本、读凭据或联网；审过脚本及其依赖后，再按任务决定是否预批准。
- **拒绝规则有覆盖范围。** `Bash(rm *)` 拦截匹配形式，不能保证涵盖程序的其他路径、shell 包装或间接子进程；`Read` 规则也不包住任意脚本的文件访问。命令拒绝清单不能代替 OS 级隔离。
- **单独限制数据与出口。** 敏感文件不要挂载或注入凭据；网络出口在覆盖相应进程的环境层限制。Claude Code 的内置 shell 沙箱不覆盖 MCP、hooks 或内置文件/网页工具，见[沙箱隔离](../00-setup-collaboration/sandbox-filesystem-isolation.mdx)与[网络出口控制](../00-setup-collaboration/network-egress-control.mdx)。
- **确认边界真的生效。** 用不含真实秘密的测试文件，检查普通读取、受保护路径、分支删除和未批准脚本分别如何处理。只检查配置能解析还不够。

## 可运行检查

在仓库根目录执行：

```bash
node examples/permissions/demo.mjs
```

[源码与运行说明](https://github.com/XuebinMa/AIWiki/blob/main/examples/README.zh-CN.md)使用合成文件，启动带 `--permission` 的真实 Node 子进程，断言允许的读写成功、未授权读写及子进程创建被拒绝，并核对文件最终状态。需要 Node.js 22.13 或更新的 22.x，或 Node.js 24+，无需安装依赖。

这个练习帮你区分“规则写出来了”和“执行时确实拒绝了”。它测试 Node 的进程权限，不测试上面的 Claude Code 匹配规则；[Node 官方](https://nodejs.org/docs/latest-v22.x/api/permissions.html)将其定位为可信代码的安全带，恶意代码、符号链接、既有文件描述符等存在边界，不能替代 OS 沙箱或网络隔离。

## 适用边界

### 适合什么时候用

- 愿意对写入、版本控制变更和仓库脚本保留交互审批的本地协作。
- 团队需要一份可裁剪、可验证的权限配置起点。

### 不适合什么时候用

- 把它直接当作无人值守执行或阻断外泄的完整策略。
- 把这一份 Claude Code 配置原样用于其他工具或不同权限模式。

### 使用前请替换

- 换成仓库实际的敏感路径、包管理器与命令；审查已有 allow 规则。
- 核查沙箱读写范围、环境变量、网络、MCP 与 hooks 各自覆盖哪些进程。
- 对照当前官方规则语法和权限模式执行上述无敏感数据的验证。
