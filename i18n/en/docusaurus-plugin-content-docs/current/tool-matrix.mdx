# Tool matrix

Capabilities change quickly. This page separates **book coverage** from **product capabilities**: an entry lacking tool-specific guidance does not establish that the product lacks a feature. Identify CLI/IDE/cloud surface, version, platform, and actual permission mode in every comparison.

## Current verification entry points

| Tool | Mechanisms checked in this refresh | What to confirm before use |
|---|---|---|
| Claude Code | Instructions and execution policies are separate; the built-in sandbox mainly covers shell commands and subprocesses | File/web tools, MCP, hooks, sensitive reads, and unsandboxed retries |
| Codex | `/plan` and native subagents exist; subagents inherit parent safety constraints | Interface, configuration precedence, network/filesystem limits, and workspace independence |
| Gemini CLI | Plan Mode and native subagents exist | Current default mode, policy, and subagent tool permissions |
| Cursor | Native subagents exist; official permissions allowlists are not a security guarantee | Editor/CLI/cloud execution location, sandbox, and team policies |
| GitHub Copilot | Distinguish completion, IDE agents, cloud coding agents, and code review | Instruction support, tool permissions, network, and review coverage for each surface |

Verified **2026-10-29**. These are checked mechanisms, not an exhaustive feature table or security ranking. Defaults and claims that a feature does not exist age especially quickly; retain uncertainty where evidence is insufficient.
