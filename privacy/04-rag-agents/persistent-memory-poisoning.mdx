> 一句话摘要：攻击者不必直接改我的记忆库。他可以把指令藏进我会读取的外部材料，诱导系统把它存成跨会话规则，等下一次正常任务再触发外泄。边界要守在记忆写入、来源保留与后续动作授权三处；新开聊天不会自动清掉已存的恶意规则。

## 机制：我这边发生了什么

你让我总结一份外部材料。材料中的一句话被当成你的长期偏好，进入了应用维护的记忆。下一次会话里，系统把这条内容重新放进我的上下文；可观察到的结果是，后续工具动作多了一个收件方或共享目标。

这里描述的是**外部存储被写入、读取与使用的行为**，不是我内省「自己记住了什么」。危险的转换发生在来源身份被抹掉时：来自网页的文字，经过摘要或记忆写入，变成看起来属于用户的规则。

```mermaid
flowchart LR
    A["不可信外部材料"] --> B["夹带指令被当成偏好"]
    B --> C["写入持久记忆"]
    C --> D["后续会话检索"]
    D --> E["正常任务中多出越权动作"]
    E --> F["私有数据离开授权边界"]
```

PMPA 预印本把这一过程分为写入与跨会话触发两个阶段。它支撑的是这种攻击路径在特定实验设置下可发生，不证明任何带记忆功能的产品都会自动中招。

## 威胁面：谁能把指令变成长期规则

威胁模型限定为：攻击者能控制你可能提交给代理的外部材料；代理有持久记忆写入与后续检索能力，并有能够传出数据的工具。攻击者不需要知道训练集，也不依赖模型权重记忆或 logprobs；攻击对象是运行时维护的外部状态。

要检查的不只最终答复：记忆写入请求、实际存储差异、来源字段、后续检索内容，以及工具调用中的收件人、访问名单和目标地址，都在证据链里。只看第一轮有没有外泄，会漏掉延迟触发。

租户隔离仍然必要，但即使同一用户自己的记忆库完全隔离，恶意规则也可能在**这个用户**的后续任务中生效。攻击不以跨用户存储 bug 为前提。

## 防护原理

本条的配方是工程建议，不是经验证的完整防御：**外部材料不能因为被存过一次，就获得用户指令的权限。** 写入时保留来源与用途，读取时保留信任等级，行动时重新核对当前任务的授权，避免靠记忆中的自然语言自行扩权。

Anthropic 的 memory tool 是客户端执行文件操作的接口，应用控制存储；这提供了加入写入校验的工程位置，但不会自动为你完成来源鉴别。一个「不要记坏东西」的提示词，也不能代替写入与工具端的限制。

## 落地实现（配方）

先把文档事实与用户认可的长期偏好分开保存。外部内容的摘要默认只作为带来源的数据，不作为行动政策。可用如下记录作为你自己存储层的设计起点：

```text
memory_record:
  content: 需要保留的最小事实
  source_id: 原材料标识与版本
  origin: 外部材料 / 用户明确要求 / 人工确认
  scope: 对应用户、项目与用途
  approved_actions: 不从本文本推导新增行动权限
  review_status: 待核对 / 已核对 / 已撤销
```

这不是某个产品现成的配置格式。实施时由记忆处理器限制可写字段、路径与归属；需要把外部内容提升为长期规则时，通过独立的可信流程确认。高风险动作还要在工具或服务端检查对象和目标，不能让记忆记录直接增加收件方或改变访问控制。

保留必要的写入与撤销审计，日志避免复制真实敏感内容。发现投毒后，撤销原记录，并追踪它派生的摘要、复制记忆与相关动作；仅清空当前聊天不够。

**最小可测试断言**：

- **怎么测**：在隔离测试环境使用合成资料与受控工具，给外部材料放入一个无真实敏感数据的“记住此规则”诱饵。结束会话，再用新会话执行会触发它的正常任务。检查记忆差异、检索结果与工具参数。
- **通过证明什么**：在这组探针和配置下，外部诱饵没有成为受信任规则，后续动作未增加未授权对象，撤销记录不会继续被使用。它不证明所有表达或触发器都已被覆盖。
- **失败看到什么**：记录丢失来源身份、摘要把外部话术改写成用户偏好，或新会话出现额外收件方/共享目标。回到写入、来源传播与工具授权三层修复。

## 真实攻击演示：PMPA 研究设置

PMPA（2026-09-12，arXiv v1，**预印本**）在 OpenClaw 与 Claude Code 上研究了通过外部材料诱导记忆写入、再跨会话触发的攻击。研究使用本地模拟工作区和研究配置的底层模型；邮件、日历、文档与表单动作由受控状态模拟。**不能把“实验里使用 Claude Code”读成“Claude 官方默认模型与默认生产环境已经被同样测过”。**

本条不搬运论文的成功率：它们绑定输入模态、模型、场景、检测口径与配置，不能当作你系统的泄露概率。这里将 `maturity` 标为**研究**，不宣称配方已在生产中获得普遍验证。

## 残余风险与权衡

- **新开会话 ≠ 清除持久记忆。** 新会话若继续读取同一存储，恶意规则仍可能回来。
- **来源标记 ≠ 强制隔离。** 标签帮助审计；模型仍会读取内容，关键权限需要工具和后端执行。
- **写入过滤 ≠ 永久防住。** 摘要、改写和多轮分散写入会改变形态，需要跨会话测试与复核。
- **只删原记录 ≠ 删除派生副本。** 摘要或其他记忆可能已复制它；已经外发的数据更不能靠删记忆收回。
- **收紧记忆会损失便利。** 不再自动固化所有偏好，会增加确认与重建上下文的成本；优先保护高敏感、高权限用途。
